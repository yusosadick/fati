# Docs

Home for project documentation, design inspiration and miscellaneous files that don't belong in `src/`.

| Folder        | Use for                                                    |
| ------------- | ---------------------------------------------------------- |
| `notes/`      | Meeting notes, decisions, ideas, scratch write-ups         |
| `assets/`     | Images, mockups, screenshots, and other files for docs     |
| `references/` | Specs, briefs, API docs, third-party material              |

Put one-off or unsorted files directly in `docs/` if they don't fit a folder yet.

## Conventions

- Markdown (`.md`) for written docs.
- Use lowercase kebab-case file names, e.g. `auth-flow.md`.
- Date-stamp notes when it matters: `2026-10-21-kickoff.md`.

## Index

- `dashbaord-inspiration.webp` — design target for the dashboard
- `notes/dashboard-design.md` — measurements, colors and known gaps
- `landing-inspiration.webp` — design target for the landing page (1680 × 8522)
- `notes/landing-design.md` — how the landing was matched, tokens, responsive rules, dashboard slot
